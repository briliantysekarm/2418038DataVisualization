# Bike Sharing Data Visualization

## Deskripsi
Data ini merupakan penerapan visualisasi data menggunakan Python untuk menganalisis dataset Bike Sharing yang bertujuan untuk mengolah data penyewaan sepeda dan menyajikan informasi dalam bentuk grafik agar pola serta perbedaan jumlah penyewaan lebih mudah dipahami. Analisis dilakukan menggunakan Google Colab dengan bantuan library Pandas dan Matplotlib.

## Latar Belakang
Dataset Bike Sharing dipilih karena memiliki berbagai variabel yang dapat digunakan untuk menganalisis aktivitas penyewaan sepeda, seperti tanggal, hari, suhu, kondisi cuaca, jumlah pengguna kasual, dan jumlah pengguna terdaftar.

Melalui visualisasi data, informasi yang awalnya berbentuk tabel dapat disajikan menjadi grafik yang lebih informatif. Dengan demikian, pola penyewaan sepeda dapat diamati berdasarkan waktu, kategori pengguna, dan kondisi cuaca.

## Tujuan
- Mempelajari proses pengolahan dan visualisasi data menggunakan Python.
- Menampilkan data penyewaan sepeda dalam bentuk grafik.
- Membandingkan jumlah penyewaan berdasarkan hari dan kondisi cuaca.
- Menganalisis perbandingan pengguna kasual dan pengguna terdaftar.
- Mengidentifikasi pola penyewaan berdasarkan hasil visualisasi.

## Tools dan Teknologi
- **Python** — bahasa pemrograman untuk analisis data.
- **Google Colab** — lingkungan untuk menjalankan kode Python.
- **Pandas** — untuk membaca, mengolah, dan mengelompokkan data.
- **Matplotlib** — untuk membuat grafik visualisasi.
- **NumPy** — untuk mendukung operasi numerik jika diperlukan.

## Visualisasi yang Dibuat
### 1. Tren Total Penyewaan Sepeda per Bulan
Menggunakan grafik garis untuk menampilkan perubahan jumlah penyewaan sepeda dari bulan ke bulan.

### 2. Total Penyewaan Sepeda Berdasarkan Hari
Menggunakan grafik batang untuk membandingkan jumlah penyewaan pada setiap hari dalam seminggu.

### 3. Perbandingan Kategori Pengguna
Membandingkan total penyewaan dari pengguna kasual dan pengguna terdaftar menggunakan grafik batang.

### 4. Total Penyewaan Berdasarkan Kondisi Cuaca
Menampilkan perbedaan total penyewaan sepeda berdasarkan kategori kondisi cuaca.

## Tahapan Pengerjaan
1. Membaca dataset Bike Sharing.
2. Memeriksa struktur dan isi dataset.
3. Menyesuaikan format tanggal dan mengurutkan data.
4. Mengelompokkan data sesuai kebutuhan analisis.
5. Membuat visualisasi menggunakan Matplotlib.
6. Menambahkan judul, label sumbu, legenda, dan angka pada grafik.
7. Menginterpretasikan hasil visualisasi.

## Kesimpulan
Visualisasi data Bike Sharing membantu menyajikan informasi penyewaan sepeda dalam bentuk yang lebih mudah dipahami. Penggunaan grafik garis dan grafik batang memungkinkan pengamatan tren serta perbandingan jumlah penyewaan berdasarkan waktu, kategori pengguna, dan kondisi cuaca.

Proyek ini juga memberikan pengalaman dalam mengolah dataset menggunakan Pandas dan membuat visualisasi menggunakan Matplotlib sebagai bagian dari proses analisis data.
